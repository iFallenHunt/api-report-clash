# Exemplos de mensagens (DADOS FICTÍCIOS)

Todos os eventos abaixo são inventados para ilustrar o formato. Gere você mesmo com:

```bash
npm run preview -- weekly --demo
npm run preview -- monthly --demo
npm run preview -- notices --demo
```

Formato: português do Brasil, blocos curtos, negrito com um asterisco, sem tabelas. Nos relatórios, ajustes/ofertas e cosméticos aparecem em listas compactas e os links oficiais ficam agrupados no rodapé; nos avisos individuais o link vai no próprio aviso. Itens da loja do evento aparecem em seção própria ("🛒 Loja do evento"), nunca como prêmio garantido. Datas no horário de Brasília. Campos ausentes não aparecem (ex.: sem término confirmado → "Término: ainda não divulgado"; sem duração calculável → linha omitida).
